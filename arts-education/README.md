# 예술교육 프로젝트

## 아직 정해지지 않은 것

이 문서의 첫 항목이 빈칸이라는 사실이 이 프로젝트의 현재 상태다.
아래 세 가지가 정해지기 전까지 폴더 구조는 잠정적이다.

- **연구질문** — 무엇을 묻는가. (예: 예술교육은 무엇을 가르친다고 주장하면서 실제로는 무엇을 분배하는가)
- **대상** — 누구의 경험을 자료로 삼는가. 학습자·교수자·정책·작품 중 어디에 초점이 있는가.
- **산출물** — 학술논문(KCI/SSCI)인가, 교육과정 설계인가, 정책 제안인가, 셋의 결합인가.

## 폴더

| 디렉터리 | 용도 |
|---|---|
| `research/` | 이론·선행연구·문헌 노트. 개념을 주조하기 전의 재료. |
| `curriculum/` | 교육과정·차시안·활동지. 이론이 몸을 얻는 자리. |
| `data-raw/` | 마이크로데이터 원본. git 제외. 접근 절차는 해당 폴더 README 참조. |
| `fieldwork/` | 현장자료·인터뷰 전사·관찰기록·설문. 사례가 들어오는 입구. |
| `drafts/` | 논문·보고서 초고. 버전은 파일명이 아니라 git으로 관리한다. |
| `assets/` | 도판·음원·영상. 대용량 원본은 커밋하지 말고 출처만 기록한다. |

## 원칙

1. 개념에서 시작하지 않는다. 사례에서 시작해 개념을 주조한다.
2. 초고는 `drafts/`에서만 자란다. 다른 폴더는 재료 창고다.
3. 이 저장소의 기존 내용(BTS Wire, 아르카디의 침묵)과 파일을 섞지 않는다.
