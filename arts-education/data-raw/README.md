## KCYPS 2018 — 한국아동·청소년패널조사

| | |
|---|---|
| 제공 | 한국청소년정책연구원(NYPI) 한국 아동·청소년 데이터 아카이브 |
| 주소 | https://www.nypi.re.kr/archive |
| 경로 | NYPI 패널조사 → 한국아동·청소년패널조사 2018 → 조사표/데이터/코드북 |
| 절차 | 회원가입 → 데이터 이용 신청 동의 → 다운로드 |
| 비용 | 무료 |
| 동봉 | 유저가이드, 코드북, 조사표 |

**패널 구성** — 두 개의 독립 코호트다.
- 초4 패널 2,607명 (2018년 초등 4학년 기준)
- 중1 패널 2,590명 (2018년 중학 1학년 기준)
- 합계 5,197명. **합쳐서 분석하면 안 된다.** 3항 참조.

**조사 주기** — 매년. 1차 2018년, 이후 연 1회.
최신 공개 차수는 아카이브에서 직접 확인할 것(2024년판 유저가이드까지 확인됨).

### 착수 전 반드시 확인할 것 — 처치 변수가 실제로 존재하는가

이 설계의 성패는 여기서 갈린다. 코드북에서 다음을 확인한다.

1. **예체능 사교육이 참여 여부·시간인가, 지출액인가.**
   사교육비 문항의 하위 항목이라면 값은 *금액*이다. 금액을 처치로 쓰면
   처치가 소득과 기계적으로 얽히고, 개인 고정효과로도 분리되지 않는다
   (소득 충격이 처치와 결과를 동시에 민다). 참여 더미나 주당 시간이
   따로 있는지 먼저 볼 것. 없다면 이 설계는 재구성해야 한다.
2. **동아리 활동에서 예술 동아리가 식별되는가.**
   "동아리 참여 여부" 하나뿐이라면 체육·학술·봉사와 구분되지 않는다.
   활동 유형 코드가 있는지 확인.
3. **행복감·우울 문항이 전 차수에 동일 문항으로 들어가는가.**
   중간에 척도가 바뀌면 고정효과 추정이 척도 변화를 효과로 읽는다.
4. **지역 변수의 해상도.** 학교알리미·예술강사 배치와 접합하려면
   최소 시군구가 필요한데, 공개본은 광역으로 뭉개져 있을 가능성이 높다.
   접합이 필요하면 별도의 제한적 이용 신청 경로를 알아볼 것.

### 설계상의 기회 — 코호트 × 코로나

두 코호트는 같은 연령을 다른 연도에 통과한다.
중1 패널은 2018년에 중1이었고, 초4 패널은 2021년에 중1이 된다.
그 사이에 코로나가 있다. 동아리·예체능 활동의 강제 중단은
개인의 선택이 아니라 **외생적 충격**이며, 자기선택 문제를 우회한다.

다만 모두가 동시에 겪었으므로 단순 전후 비교는 시간 효과와 구분되지 않는다.
식별에 쓰려면 중단 강도의 *차등* — 지역별 거리두기 단계, 학교급별 등교
재개 시차 — 을 처치 강도로 삼아야 한다. 이건 별도 검토가 필요하다.

## KLoSA — 고령화연구패널조사

| | |
|---|---|
| 제공 | 한국고용정보원(KEIS) 고용조사 분석시스템 |
| 주소 | https://survey.keis.or.kr/klosa/klosadown/List.jsp |
| 절차 | 회원가입 → 다운로드. 온라인 자료분석 시스템도 별도 제공 |
| 비용 | 무료 |
| 동봉 | 유저가이드, 코드북, 설문지 (각각 별도 메뉴) |
| 대상 | 2006년 기준 제주 제외 지역 45세 이상 중고령자 |

### 주의 — **기본조사는 격년이다**

2006년부터 **짝수 연도**에 동일 항목으로 기본조사를 하고,
2007년부터 홀수 연도에는 기본조사에 없는 내용을 중심으로 부가조사를 한다.
따라서 시계열은 2006, 2008, … 2022(9차), 2024(10차)로 **2년 간격**이다.

이것이 설계에 미치는 영향은 작지 않다.

- 처치 시작 시점을 2년 해상도로만 관측한다. "여가·예술 활동을 시작한 해"를
  특정할 수 없다.
- 두 조사 사이에 시작했다가 그만둔 경우는 **관측되지 않는다.**
  노년기 활동의 상당수가 여기 해당할 것이다.
- 사건연구의 pre-trend를 볼 시점이 2년 간격 서너 개뿐이다.
- 45세 이상에서는 2년 사이에 은퇴·사별·건강 충격이 일어난다.
  시변 교란이 처치 창 안에 통째로 들어온다.

### 대안 — 노인판은 한국복지패널이 낫다

| | KLoSA | 한국복지패널 |
|---|---|---|
| 주기 | 격년 | **매년** |
| 우울 | CES-D 10 | CES-D 11 |
| 기간 | 2006~ | 2006~ |
| 여가·문화 문항 | 상세 | 확인 필요 |

주기가 결정적이다. 복지패널의 여가·문화 활동 문항이 처치 변수로 쓸 만큼
구체적인지 코드북으로 확인한 뒤 결정할 것. KLoSA는 문항이 풍부하되
시간 해상도가 낮고, 복지패널은 그 반대일 가능성이 크다.
둘 다 받아서 문항을 대조하는 것이 순서다.

한국복지패널: 한국보건사회연구원 https://www.koweps.re.kr

```
arts-education/
├── data-raw/          ← 원본 (git 제외)
│   ├── kcyps2018/
│   ├── klosa/
│   └── koweps/
├── research/          ← 코드북 검토 노트
└── drafts/
```

작업 순서: 받기 → **코드북에서 처치 변수 존재 확인** → 있으면 기술통계 →
사건연구 pre-trend → 그 다음에 추정.
처치 변수가 없으면 그 앞의 모든 계획이 무의미하므로, 두 번째 단계에서
결론이 날 수도 있다.
